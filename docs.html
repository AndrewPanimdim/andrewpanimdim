Documentation

Everything about my portfolio website: what it is made of, how each part works, the small API behind it, and the npm package I publish from the same repository.

The project has three parts that live in one repository:

WebsiteVite + TypeScript
→
APIFastAPI (Python)
→
Databackend/me.json
  • The website is a single-page front end written in plain TypeScript and CSS (no framework). Each part of the page is its own small module.
  • The API is a tiny read-only FastAPI app that returns information about me as JSON. The website reads from it, and anyone can call it.
  • The npm package andrewpanimdim contains the effects the website uses (text scramble, text split, drag with momentum, the growing cursor). The website installs it like any other dependency.

Getting started

You need Node.js 22 and, to run the API locally, Python 3.12.

Run the website

git clone https://github.com/AndrewPanimdim/andrewpanimdim.git
cd andrewpanimdim
npm install
npm run dev

Open the address Vite prints (usually http://localhost:5173).

Run the API (second terminal)

python -m venv backend/.venv

# Windows PowerShell
backend\.venv\Scripts\Activate.ps1
# macOS / Linux
# source backend/.venv/bin/activate

pip install -r backend/requirements.txt
npm run dev:api

The API starts on port 8000. The dev server forwards every /api request to it, so the website works without any extra setup. If the API is not running, the page still loads and shows its built-in fallback text.

How the app works

Page load, step by step

  1. The browser loads index.html. It contains only an empty <div id="app"> and a script tag.
  2. src/main.ts runs. It imports global.css and writes the page markup (#hello, #aboutme, #float, #moreAM) into #app.
  3. main.ts then calls one function per section, so every section finds its element already on the page.
  4. Sections that need data (aboutme, the project cards, the GitHub badge) fetch it in the background. Each one has fallback content, so a slow or offline API never leaves a blank space.

The files in src/

FileWhat it does
main.tsThe entry point described above
api.tsapiUrl(path) puts the VITE_API_URL prefix in front of a path. fetchJson<T>(path) fetches it and throws if the response is not OK
sections/hello.tsSplits "Hello, World" into words and fades them in one by one with splitText, then undoes the split and scrambles it into "Hello, I'm Andrew" with scrambleText
sections/aboutme.tsLoads /api/me and /api/facts, then cycles through the lines with slide-in and slide-out animations. Uses built-in lines if the API is unreachable
sections/float.tsMakes the #float glass box draggable with momentum using draggable (the box is currently hidden in the CSS)
sections/cursortrack.tsCreates the #cursertrack dot and starts cursertrack. The dot grows when the mouse moves fast and hides when the pointer leaves the page
sections/topnav.tsThe floating navigation pill. It compresses when you scroll down and widens when you scroll up. The Docs button lives on its left
sections/githubbadge.tsThe GitHub link in the top-right corner with a live star count. It slides in at the top of the page and away when you scroll
sections/scrolldelay.tsSmooth, slightly delayed mouse-wheel scrolling. It stops its animation loop once settled so keyboard and touch scrolling are not disturbed
sections/moreAM.tsThe "more about me" project cards (see below)
sections/backgroundparticles.tsOptional floating dots. It is commented out in main.ts
projects.tsBuilds the projects page from /api/projects
docs.tsPowers this page: copy buttons, the highlighted table of contents and the "Try it" buttons

The project cards (moreAM.ts)

Each card is one entry in the CARDS list at the top of the file: 

{ id: 'am-a', title: 'Portfolio site', gif: 'a.gif', repo: 'andrewpanimdim', stack: ['TypeScript', 'Vite', 'FastAPI'] }
FieldMeaning
idThe element id, used by the CSS to place and animate the card (#am-a, #am-b, ...)
titleThe name shown under the GIF
gifFile name inside public/gif/
repoOptional. A repository name under my GitHub account. When set, the chips are filled from GitHub
stackThe chips shown first, and kept if GitHub cannot be reached
  • Reveal on scroll. An IntersectionObserver adds the class visible to a card when 20% of it is on screen. The CSS then transitions it from its hidden state (faded and shifted) to its final place. JavaScript only toggles the class; the CSS does the animating.
  • Tech-stack chips. For a card with a repo, two public GitHub requests are made: /repos/{user}/{repo}/languages (top three languages) and /repos/{user}/{repo} (topics). Up to four chips are shown. The answer is cached in localStorage for one hour because GitHub allows 60 requests per hour per visitor without a token.
  • Safe rendering. Text that comes from GitHub is inserted with textContent, never as HTML.

API

A small, read-only JSON API built with FastAPI. All routes live under /api, accept only GET, HEAD and OPTIONS, and allow requests from any origin (CORS), because the data is public.

WhereBase URL
Productionhttps://andrewpanimdim.vercel.app/api
Local (through Vite)http://localhost:5173/api
Local (direct)http://127.0.0.1:8000/api

FastAPI also generates interactive documentation: /api/docs (Swagger UI), /api/redoc and the raw schema at /api/openapi.json.

Try it

These buttons call the API your copy of the site is configured to use and show the real response.

Filtering

  • /api/skills?category=frontend returns only skills in that category. level works the same way (for example level=intermediate). Both ignore letter case and can be combined.
  • /api/projects?tag=python returns only projects whose tags include that value. Matching is exact, and the query is lowercased, so use lowercase tags such as python or javascript.

Calling it

From a terminal:

curl https://andrewpanimdim.vercel.app/api/me

From the website's own code, using the helper in src/api.ts:

import { fetchJson } from './api.ts'

type Skill = { name: string; level: string; category: string }

const skills = await fetchJson<Skill[]>('/api/skills?category=frontend')

fetchJson adds the VITE_API_URL prefix when one is set (see Configuration) and throws an error for any non-OK response, so wrap it in try/catch and keep a fallback.

Changing the data

All the content comes from backend/me.json, with the top-level keys profile, facts, skills, projects and socials. Edit that file and the API serves the new content; npm run dev:api reloads automatically when a .json file changes. Keep each project's id a number, because the single-project route compares it with the number in the URL.

npm package: andrewpanimdim

Tiny, dependency-free web effects for any website, with TypeScript types included. The source lives in the library/ folder of this repository, and the website itself uses the published package. Every effect respects prefers-reduced-motion, and you only ship the features you import.

FeatureWhat it does
scrambleTextText appears by unscrambling random characters
splitTextWraps each word or letter in a span so you can animate them one by one
draggableDrag an element with mouse, touch or pen and throw it with momentum
cursertrackA cursor dot that grows when you move fast and hides when the pointer leaves the page
scrolltiltRotates, tilts and scales an element as the page scrolls

Install

npm install andrewpanimdim

Import

Everything from the main entry:

import { scrambleText, splitText, draggable, cursertrack, scrolltilt } from 'andrewpanimdim'

Or one feature from its own path, which keeps your bundle smaller:

import { scrambleText } from 'andrewpanimdim/scramble'
import { splitText } from 'andrewpanimdim/split'
import { draggable } from 'andrewpanimdim/draggable'
import { cursertrack } from 'andrewpanimdim/cursortrack'
import { scrolltilt } from 'andrewpanimdim/scrolltilt'

The functions need document and window, so they run in the browser. With server rendering (Next.js, Nuxt) call them from client-side code, for example inside useEffect.

scrambleText

Animates an element's text from random characters into the real text.

const title = document.querySelector<HTMLElement>('#title')!
const anim = scrambleText(title, { text: "Hello, I'm Andrew", duration: 1500 })

await anim.finished   // resolves when the animation ends

Signature: scrambleText(element, options?) → { finished, cancel }

OptionTypeDefaultDescription
textstringthe element's current textThe text to reveal
durationnumber1500Total time in milliseconds
from'left' | 'right' | 'center' | 'random''left'Where the reveal starts
charsstringletters, digits and symbolsThe characters used for the scrambled letters
onUpdate(text) => voidnoneCalled every frame with the text being shown
random() => numberMath.randomCustom random source (useful for tests)
respectReducedMotionbooleantrueSkip the animation for visitors who prefer reduced motion

Returns: finished is a Promise that resolves when the animation ends or is cancelled. cancel() stops immediately and shows the final text.

// Reveal from the middle outward, using only 0s and 1s
scrambleText(el, { text: 'ACCESS GRANTED', from: 'center', chars: '01' })

// Chain animations
await scrambleText(el, { text: 'Loading...' }).finished
await scrambleText(el, { text: 'Done!' }).finished

splitText

Wraps each word (or letter) in a <span> so you can animate the pieces separately.

const { elements, revert } = splitText(heading, { by: 'words' })

elements.forEach((word, i) => {
  word.animate(
    { opacity: [0, 1] },
    { duration: 600, delay: i * 150, fill: 'backwards' },
  )
})

revert()   // later: put the element back exactly as it was

Signature: splitText(element, options?) → { elements, revert }

OptionTypeDefaultDescription
by'words' | 'chars''words'Split into words or single characters
classNamestring'tfx-piece'CSS class given to every span

Good to know: the pieces are display: inline-block so transforms like translateY work. The parent gets an aria-label with the full sentence and the pieces are aria-hidden, so screen readers still read the real text. Only use it on plain text elements, because it replaces the element's contents.

draggable

Makes an element draggable with mouse, touch or pen. When released, it keeps gliding and slows down.

const box = document.querySelector<HTMLElement>('#box')!

const drag = draggable(box, {
  container: 'main',
  containerPadding: 10,
  friction: 6,
  onGrab: (el) => el.classList.add('grabbed'),
  onRelease: (el) => el.classList.remove('grabbed'),
})

drag.destroy()   // later: remove listeners and put the element back

Signature: draggable(element, options?) → { destroy }

OptionTypeDefaultDescription
containerHTMLElement | stringnone (free movement)Keep the element inside this element or CSS selector
containerPaddingnumber0Pixels of space to keep from the container edge
frictionnumber6How fast a thrown element slows down. Higher stops sooner
onGrab(el) => voidnoneCalled when the pointer grabs the element
onRelease(el) => voidnoneCalled when the pointer lets go

Movement uses CSS transform, so do not set your own transform on the same element.

cursertrack

A cursor dot that follows the mouse. It grows when you move fast, eases back to normal size when you slow down, and fades out when the pointer leaves the page or window. 

const dot = document.createElement('div')
dot.id = 'cursertrack'
document.body.appendChild(dot)

const tracker = cursertrack(dot, { maxScale: 5 })

tracker.destroy()   // later: stop tracking and reset

Style the dot yourself. It must be fixed in the top-left corner so the library can position it:

#cursertrack {
  position: fixed;
  top: 0;
  left: 0;
  width: 24px;
  height: 24px;
  border-radius: 50%;
  background: #fff;
  pointer-events: none;
  z-index: 9999;
}

Signature: cursertrack(element, options?) → { destroy }

OptionTypeDefaultDescription
thresholdnumber1.2Speed (px per ms) below which the cursor counts as moving normally
maxSpeednumber5Speed at which the dot reaches its biggest size
maxScalenumber5The biggest size multiplier
grownumber0.01How fast it grows. Higher is snappier
shrinknumber0.004How fast it returns to normal. Lower is slower and smoother
followbooleantrueMove the element to the pointer too. Set false to only scale it
hideOutsidebooleantrueFade out when the pointer leaves the page or window
edgenumber2Pixels from the window edge that count as leaving

Tuning: if the dot grows too easily, raise threshold. If it returns to normal too quickly, lower shrink. For a stronger reaction to quick flicks, raise maxScale or lower maxSpeed.

scrolltilt

Rotates, tilts, scales and shifts an element as the page scrolls, easing smoothly between the start and end positions.

const tilt = scrolltilt(image, { start: 0, end: 800, rotate: 12, scale: 1.1 })

tilt.destroy()   // later: stop and restore the element's transform

Signature: scrolltilt(element, options?) → { destroy }

OptionTypeDefaultDescription
startnumber0Scroll position (px) where the effect begins
endnumber1000Scroll position (px) where it finishes
rotatenumber12Flat rotation in degrees at end
rotateXnumber03D tilt forward or back in degrees at end
rotateYnumber03D tilt left or right in degrees at end
scalenumber1Size at end; 1 means unchanged
translateYnumber0Extra vertical shift in px at end
smoothnumber0.120 to 1. Lower is floatier, 1 is instant

Using it with React

Call the functions inside useEffect and clean up when the component unmounts:

import { useEffect, useRef } from 'react'
import { scrambleText, draggable } from 'andrewpanimdim'

export function Hero() {
  const title = useRef<HTMLHeadingElement>(null)
  const box = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const anim = scrambleText(title.current!, { text: 'Hello, world' })
    const drag = draggable(box.current!)
    return () => {
      anim.cancel()
      drag.destroy()
    }
  }, [])

  return (
    <>
      <h1 ref={title}>Hello</h1>
      <div ref={box} style={{ width: 80, height: 80 }} />
    </>
  )
}

How the package is built

  • Pure core, thin shell. Each feature keeps its maths in small pure functions (easy to test) and a thin shell that attaches events and animation frames.
  • Handles. Features return a handle (destroy() or cancel()) that removes listeners and restores whatever the feature changed.
  • Output. tsup builds ES modules, CommonJS and type declarations for every entry. The exports field in package.json maps each subpath (/scramble, /split, ...) to its files, and files limits what gets published to dist, the README and the license.
  • Zero dependencies. Nothing is installed alongside it, which keeps the package small and its attack surface minimal.

Working on it and publishing a new version

Run these from inside the library/ folder, not the project root:

cd library
npm install
npm test            # Vitest (pure logic + jsdom)
npm run typecheck
npm run build       # writes dist/

npm version patch   # or minor / major: bumps package.json
npm publish         # prepublishOnly runs typecheck, tests and build first

Published versions are permanent and cannot be overwritten, so every change needs a new version number. Publishing requires an npm account with two-factor authentication turned on. If npm publish answers 404 or 403, log in again with npm logout then npm login.

Deployment

Every push to main runs .github/workflows/deploy.yml (Node 22), which publishes the site to two places:

JobWhenWhat it does
build-pagesPush to main, or run by handInstalls, then builds with BASE_PATH=/andrewpanimdim/ and the API address baked in, and uploads dist/
deploy-pagesAfter build-pagesPublishes the upload to GitHub Pages
vercel-productionPush to main, or run by handBuilds and deploys the front end and the API to Vercel production
vercel-previewPull requestsDeploys a preview so changes can be checked before merging

Why two hosts?

  • Vercel runs both the static site and the Python API. vercel.json defines two services (frontend from the project root and backend from backend/) and rewrites /api and /api/* to the backend and everything else to the front end.
  • GitHub Pages can only serve static files, so it cannot run Python. That build calls the live Vercel API instead, through VITE_API_URL.
  • The two hosts use different base paths: Pages serves the site from /andrewpanimdim/ and Vercel from /. The code therefore builds asset links from import.meta.env.BASE_URL and never hard-codes a leading slash.

Security notes

  • Read-only API. It answers only GET, HEAD and OPTIONS, and serves only public information from a static JSON file. There is no database and no user input is stored.
  • No HTML injection. Text from the API and from GitHub is written with textContent, and project links are only accepted when they start with http or https.
  • Secrets stay out of the code. Deployment tokens live in GitHub Actions secrets, and .env files are git-ignored.
  • Package hygiene. The npm package has no runtime dependencies, publishes only the files listed in files, and is published from an account with two-factor authentication.
  • Browser-side requests. The only third-party calls the page makes are to Google Fonts and the public GitHub API.

Troubleshooting

ProblemFix
A GIF shows locally but is missing on VercelFile names are case-sensitive on Vercel's servers. Make the name in CARDS match the file exactly, including capitals
Assets or pages 404 on GitHub PagesThe site must be built with BASE_PATH=/andrewpanimdim/. The workflow does this; a plain local build does not
The page shows fallback text instead of API dataThe API is offline or unreachable. Locally run npm run dev:api. On Pages check VITE_API_URL. If the Vercel API answers 401, turn off Deployment Protection for production

npm run build says it cannot resolve an HTML pageEvery page listed in build.rollupOptions.input must exist in the project root
npm publish answers 403 or 404Turn on two-factor authentication, then npm logout and npm login. A version number can only be published once
The website still uses old library behaviorAfter publishing a new version, run npm install andrewpanimdim@latest in the project root
